Установить python 3.10.8 64 бита

Создать виртуальное окружение с этим питоном
python -m venv venv

Запустить окружение
venv\Scripts\activate

Установить библиотеку 
pip install pyodbc

Альтернатива 
pip install pyodbc -i https://pypi.tuna.tsinghua.edu.cn/simple
